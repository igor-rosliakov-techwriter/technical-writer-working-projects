# CloudBox CLI: Installation and Setup

# CloudBox CLI installation

CloudBox CLI is a tool for working with cloud files. It is very easy to install and use.

## Installation

First install Python. Then install CloudBox using the command:

```bash
pip install cloudbox-cli
```

After installation, run:

```bash
cloudbox
```

If everything works, you can start using it.

## Configuration

Before uploading files, configure your account:

```bash
cloudbox config --token YOUR_TOKEN
```

You can get the token from your CloudBox account.

## Uploading files

To upload a file, use:

```bash
cloudbox upload file.txt
```

The file will be uploaded to the cloud. You can also upload other files.

## Troubleshooting

If something doesn't work, try reinstalling the application or contact support.
